# Tengo Libre · iPhone

La app de iPhone de [Tengo Libre](https://tengolibre.com.ar): SwiftUI, iOS 17, sin dependencias. El
proyecto de Xcode sale de `project.yml` (`xcodegen generate`). Se compila sólo en GitHub Actions
(`ios.yml`) y cada compilación verde de `main` sube sola a TestFlight (`testflight.yml`).

El código vive en el monorepo `tengolibre` (`apps/ios`) y se publica acá para compilar.
